2. Checkout data flow

Select product→ Phone / account→ Address→ PendingCheckout→ Razorpay pay→ Paid Order
Rule: A real orders document is created only after Razorpay payment signature verification. Unpaid attempts stay in pendingcheckouts and expire via TTL.
